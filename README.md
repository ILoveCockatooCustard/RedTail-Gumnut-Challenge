# Before Installing
Make sure you download the **Latest Version**, and if your browser reports it as dangerous click 3 dots then keep. Also, please report the error to Microsoft.<br>
Also, make sure you change your name in **Settings** before you start playing, hopefully we will fix this soon.<br>
