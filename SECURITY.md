# Security Policy

Please tell us anything about the game that can cause a security issue immediately as we want to keep everyone safe.

## Supported Versions

These are the version that are supported.

| Version | Supported          
| ------- | -----------------------------------                
| 1.0.1   |  ❌ Do not use                   |
| 1.0.2   |  ❌ Do not use                   |
| 1.0.3   |  ❌ Do not use                   |
| 1.0.4   |  ❌ Could Use but not supported  |
| 1.0.5   |  ✅ (latest)                     |

## Reporting a Vulnerability

If you see anything that is a vulnerability to our game, please report it immediately, we want to keep our users safe and happy at the same time. 

Please go to [the issues page](https://github.com/ILoveCockatooCustard/RedTail-Gumnut-Challenge/issues), and use the Vulnerability Issue template. We will fix the vulnerability in less than 3 days
