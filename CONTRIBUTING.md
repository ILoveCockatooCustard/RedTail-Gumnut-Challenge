# Contributing Policy

Thank you for your interest in RedTail Gumnut Challenge.

At this time, RedTail Gumnut Challenge is **Closed Source**, meaning our code is not available for people to see, and is private.<br>
This means that we are _not accepting_ **modified games (different sounds/textures), or any way of stealing and publishing the code**.

You are welcome to:
- Report bugs
- Suggest new features
- Provide feedback
- Report compatibility issues
- Suggest improvements to gameplay or accessibility
- Pull Request the files such as README.md or SECURITY.md
- Pull Request the issue template.

Please do not submit:
- Modified builds of the game
- Repackaged or redistributed versions
- Reuploads of game assets
- Derivative versions of the game

All source code and original game assets remain All Rights Reserved unless otherwise stated.

If you would like to suggest an idea or report an issue, please use the [GitHub Issues](https://github.com/ILoveCockatooCustard/RedTail-Gumnut-Challenge/issues) page.

Thank you for helping improve RedTail Gumnut Challenge.
