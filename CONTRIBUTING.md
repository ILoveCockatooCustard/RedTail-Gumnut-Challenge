# Contributing Policy

Thank you for your interest in RedTail Gumnut Challenge.

At this time, this project is **not accepting external code contributions, pull requests, forks for redistribution, or modified versions of the game**.<br>
For security reasons, this game is also **NOT** Open Source, so please don't request for the game's code.

You are welcome to:

- Report bugs
- Suggest new features
- Provide feedback
- Report compatibility issues
- Suggest improvements to gameplay or accessibility

Please do not submit:

- Pull requests containing code changes
- Modified builds of the game
- Repackaged or redistributed versions
- Reuploads of game assets
- Derivative versions of the game

All source code and original game assets remain All Rights Reserved unless otherwise stated.

If you would like to suggest an idea or report an issue, please use the GitHub Issues section.

Thank you for helping improve RedTail Gumnut Challenge.
